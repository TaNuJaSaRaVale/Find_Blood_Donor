# public/: static files

Files here are served as-is at the site root (e.g. `/icon.svg`).

| File | Purpose |
|---|---|
| `icon.svg` | App logo: favicon, navbar logo and home-screen icon |
| `manifest.webmanifest` | Makes the site an installable **PWA**: on a phone choose "Add to Home screen" and it opens full-screen like an app |
